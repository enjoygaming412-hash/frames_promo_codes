FAQ

Everything members ask about daily rewards.

Why can’t I claim twice?

Each Minecraft username can claim once every 24 hours. The cooldown is stored in our database, so refreshing, reopening the site or using another browser does not reset it. When you are on cooldown the claim form shows the exact time your next claim unlocks.

Does yesterday’s code still work?

No. Only the current day’s promo code is accepted. Codes switch automatically at midnight in the America/Toronto timezone.

What happens when a code runs out of claims?

Every daily code has a maximum number of claims. Once that limit is reached the code stops accepting claims and a new code drops at midnight.

How long does delivery take?

Your reward has been claimed! Delivery may take up to 3 days. Staff deliver rewards in-game and mark the claim as delivered in the admin panel.

Do I need an account?

No account, no email and no payment. Just the daily promo code and your Minecraft username.
